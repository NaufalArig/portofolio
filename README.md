# Portfolio Naufal Arig

Portfolio pribadi berbasis Next.js, React, TypeScript, dan Framer Motion.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Build

```bash
npm run build
```

Project ini menggunakan static export Next.js (`output: "export"`), sehingga hasil build berada di folder `out/` dan dapat di-deploy ke Vercel.

## Screenshot proyek AirSense

Screenshot AirSense berada di `public/projects/` dan ditampilkan pada bagian Proyek akademik. Klik thumbnail untuk membuka preview ukuran besar.
